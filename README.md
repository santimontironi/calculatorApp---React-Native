# App Calculator 🧮

Aplicación de calculadora hecha con [Expo](https://expo.dev) y React Native. Es un **proyecto de práctica** para iniciarme en el desarrollo con React Native.

## Empezar

1. Instalar dependencias

   ```bash
   npm install
   ```

2. Iniciar la app

   ```bash
   npx expo start
   ```

En la salida del comando vas a encontrar opciones para abrir la app en:

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [emulador de Android](https://docs.expo.dev/workflow/android-studio-emulator/)
- [simulador de iOS](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), un sandbox limitado para probar el desarrollo con Expo

Podés empezar a desarrollar editando los archivos dentro del directorio **src/app**. Este proyecto usa [file-based routing](https://docs.expo.dev/router/introduction).

### Otros pasos de configuración

- Para configurar ESLint, ejecutá `npx expo lint`, o seguí la guía ["Using ESLint and Prettier"](https://docs.expo.dev/guides/using-eslint/)
- Para configurar tests unitarios, seguí la guía ["Unit Testing with Jest"](https://docs.expo.dev/develop/unit-testing/)
- Aprendé más sobre la configuración de TypeScript en la guía ["Using TypeScript"](https://docs.expo.dev/guides/typescript/)
